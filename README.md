# Nostra

Nostra is a responsive clothing store website built with HTML, Tailwind CSS and vanilla JavaScript. It has three pages: Home, Collections and Contact.

## Features

- **Responsive layout** that works on mobile and desktop
- **Side navigation drawer** on mobile that slides in from the left
- **Closable top banner** for offers
- **Image slider** on the home page with previous/next buttons
- **Wishlist hearts** that turn red when clicked
- **Scroll reveal animations** using IntersectionObserver
- **Collections page** with search and filters (Occasion, Color, Arrivals)
- **Contact form** with validation for name, age and message

## Getting Started

1. Clone the repository:

```
   git clone https://github.com/praveen-analyze/nostra.git
```

2. Open the project folder:

```
   cd nostra
```

3. Open `index.html` in your browser. No build step or installation is needed.

> An internet connection is required, since Tailwind CSS and Google Fonts load from a CDN.
